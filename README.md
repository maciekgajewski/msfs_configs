# FSMapper config scripts

FSMapper is a tool that allows scripting input devices (joystick, hotas etc) interaction with flight simulator.

This repo is my collection of scripts I use for the following planes in MSFS (2020 and 2024)

- Beech 18 (with Denarq mod)
- PLZ Wilga (by Got Friends)
- Aerostar 600 (by A2A)

My hardware:
- Thurstmaster A-10 Wartghog hotas
- Virpil Control Panel 3
